Same agent, made learnable

States, actions, ε-greedy and the two-table update mirror controller_doubleQ_working.py. The original reward was a flat −1 per frame, which gives every action the same value; here the reward is metres of track progress, −0.6 per frame off the asphalt, −15 per rescue and +30 for finishing a lap.

A proper Double Q update

On each step one table is picked at random. It chooses the best next action, and the other table scores it: Q_A(s,a) += α[r + γ·Q_B(s′, argmax Q_A(s′,·)) − Q_A(s,a)]. The original bootstrapped from the same action and a guessed next state instead of the observed one.

Things to try

Hit Reset and watch Turbo learning from scratch. Set γ to 0 and see it drive greedily for the next metre only. Train on Oval, then switch to Hairpins: the table carries over, so you can see how well it transfers.
